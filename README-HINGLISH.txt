DEALKHOJ - FRONTEND PROTOTYPE
==============================

RUN:
1. Extract DealKhoj.zip if needed.
2. Open the DealKhoj folder in Visual Studio Code.
3. Install the "Live Server" extension by Ritwick Dey.
4. Right-click index.html -> Open with Live Server.

FILES:
- index.html : page structure
- style.css  : design and responsive layout
- script.js  : demo products and interactions

IMPORTANT:
This is a standalone frontend prototype only.
Prices and discounts are illustrative demo data.
Retailer buttons open retailer homepages, not product-specific affiliate links.
No affiliate tracking, APIs, WordPress database, or commissions are active.
Product images and fonts load from external services and need an internet connection.
The About, Contact, Privacy and Terms links are placeholders at this stage.
